# 🤖 Nexus AI - AI Chat Interface

Сучасний чат-інтерфейс з підтримкою OpenRouter AI. Готовий до продажу та розгортання!

## ✨ Функціональність

- 💬 Чат з AI в реальному часі
- ⌨️ Підтримка Enter для відправки повідомлень
- 📜 Автоматичний скрол при довгих відповідях
- 🗑️ Кнопка очистити чат
- 🔑 Безпечне зберігання API-ключа (LocalStorage)
- 🎨 Красивий glassmorphism дизайн
- 📱 Responsive - працює на всіх пристроях

## 🚀 Швидкий старт

### Варіант 1: Локальне використання
1. Завантажте або клонуйте репозиторій
2. Відкрийте `index.html` у браузері
3. Введіть ваш OpenRouter API-ключ
4. Починайте спілкуватися!

### Варіант 2: На вебсайті
1. Завантажте `index.html`
2. Закиньте на ваш хостинг (GitHub Pages, Vercel, Netlify)
3. Давайте посилання користувачам

## 🔑 Як отримати API-ключ

1. Перейдіть на [openrouter.ai](https://openrouter.ai)
2. Зареєструйтесь / Авторизуйтесь
3. Перейдіть в `Keys` / `API Keys`
4. Створіть новий ключ
5. Скопіюйте його у форму при першому відкритті

## 📋 Що включено

- ✅ Повний HTML/CSS/JS в одному файлі
- ✅ Без зовнішніх залежностей
- ✅ Немає хардкодованих ключів
- ✅ Безпечне зберігання в браузері
- ✅ Українська мова за замовчуванням

## ⚙️ Налаштування

### Змінити модель AI
Відкрийте `index.html` і знайдіть рядок:
```javascript
model: "openrouter/auto",
```

Замініть на улюблену модель:
- `meta-llama/llama-2-70b`
- `mistralai/mistral-7b`
- `openrouter/auto` (автоматично обирає найбільш доступну)

### Змінити мову
Знайдіть рядок:
```javascript
{ role: "system", content: "Ти корисний асистент. Відповідай українською мовою." }
```

Замініть на свою мову.
